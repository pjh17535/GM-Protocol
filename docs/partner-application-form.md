# Partner application form: question list

Create a Google Form with these questions, then paste its public link into
`GOOGLE_FORM_URL` in `src/data/partners.ts`. Until it is set, the Partners page
shows "Applications Opening Soon".

Form settings: collect email addresses, one response per person off, title
"GM Protocol Partner Application", description "Apply to integrate your project
with GM Protocol on Arc. We review within 48 hours."

## Project
1. Project name (short answer, required)
2. One-sentence description (paragraph, required, max 200 characters)
3. Website (short answer, required)
4. X / Twitter (short answer)
5. GitHub (short answer)
6. Logo URL, square, at least 256 px (short answer)
7. Which chain is your project live on? (multiple choice: Arc, Other EVM, Not live yet)

## Integration
8. Operator wallet address. This wallet funds the reward pool and cannot withdraw (short answer, required)
9. How many milestone tiers do you want? (multiple choice: 1, 2, 3, 4)
10. Streak length for each tier, in days. Minimum 7, maximum 365 (short answer, required)
11. Planned USDC injection. Mainnet minimum is 2,000 USDC (short answer, required)

## Review
12. What do your users learn or do daily with your project? Education-first only, no social or referral tasks (paragraph, required)
13. Anything else we should know (paragraph)

## Confirmations (checkboxes, all required)
- I understand the check-in fee is fixed at 0.1 USDC and split 80% rewards / 10% main GM pool / 10% buyback and burn.
- I understand the funding window is 7 days after the contract is deployed.
- I understand this is a testnet program until mainnet launch.
