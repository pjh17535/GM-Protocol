## 1. 项目概述

### 1.1 项目定位

GM Protocol 是部署在 Arc Network 上的链上每日签到身份系统，同时也是 Arc 生态的链上信誉基础设施层。

**双重价值层：**
- **表层**：每日 GM 签到的参与激励系统，用户通过连续签到积累里程碑，获得 gArc 代币奖励
- **底层**：基于时间加权的链上身份证明系统，连续签到记录 + 多层身份验证 = Arc 生态的真实用户身份凭证

### 1.2 核心差异化

| 维度 | 同类项目 | GM Protocol |
|------|---------|-------------|
| 经济模型 | 纯补贴，无自循环 | GM 池自然流入，永续可持续 |
| 激励来源 | 项目方单向投入 | 断签用户补贴坚持用户 |
| 身份价值 | 无 | 时间加权链上身份凭证 |
| 防女巫机制 | 弱或无 | 多层递进式验证 |
| 代币经济 | 纯通胀 | 铸造100亿立即销毁2.1亿，有效97.9亿，通缩至底线2.1亿 |
| 透明度 | 部分链上 | 最大限度链上实现（约 85-90%） |

### 1.3 核心理念

> "通过坚持签到证明你是真实存在的 Arc 用户，通过时间积累建立链上信誉，通过经济激励让坚持变得有价值。"

## 2. 核心问题与解决方案

### 2.1 解决的问题

**问题一：链上身份识别**
Arc 生态缺乏原生的真实用户识别机制。空投、治理、合作项目无法有效区分真实用户和女巫地址。

**问题二：用户留存激励**
大多数 Web3 激励系统依赖一次性空投，用户获得奖励后即离开。缺乏长期参与的经济激励。

**问题三：可持续的代币经济**
绝大多数项目代币依赖持续的外部资金补贴，一旦资金耗尽系统崩溃。

### 2.2 解决方案

**核心洞察**：连续签到系统的经济本质是"断签用户的资金补贴坚持用户"。这是一个天然自循环的经济模型，不需要持续外部资金注入即可永续运行。

## 3. 产品设计

### 3.1 基础签到机制

- 每日签到一次，**每日 UTC 00:00 刷新**（固定时间刷新，非以上次签到时间为基础的24h冷却）
- 签到费用：**0.1 USDC**（可通过 DAO 治理调整，符号 `f`）
- 签到即记录，链上永久可查
- Arc 上 USDC 即为原生 Gas，签到体验极简
- 当日有效签到窗口：UTC 00:00 — 23:59:59，逾期视为断签

### 3.2 里程碑体系

设置 4 个核心里程碑：

| 里程碑 | 连续天数 D | 徽章等级 | 奖励池释放比例 r |
|--------|---------|---------|-------------|
| 铜牌 | 30 天 | Bronze SBT | 1.5%（0.015） |
| 黄金 | 90 天 | Gold SBT | 10%（0.10） |
| 铂金 | 180 天 | Platinum SBT | 15%（0.15） |
| 传奇 | 365 天 | Legend SBT | 18%（0.18） |

**释放机制**：
- 每日 UTC 00:00 快照，里程碑达成后次日开放 Claim
- 同一天达成的用户共享当期释放的百分比，按人数均分（公式见附录 C.2）
- 每个里程碑可重复触发（断签重置后重新积累，同一里程碑可多次 Claim）
- 释放比例遵循反向三次函数趋势：铜牌低平，黄金急速跳升，铂金/传奇趋于平稳（公式见附录 C.5）

### 3.3 SBT 徽章（灵魂绑定代币）

- 每个里程碑铸造对应等级 SBT，不可转让
- SBT 记录：达成时间、连续天数、第几轮达成
- 对外提供查询接口：第三方合约可查询某地址的最高里程碑等级
- SBT 同时作为 DAO 治理的资格凭证（详见 6.5）
- 这是 GM Protocol 作为 Arc 链上身份基础设施的核心资产

### 3.4 合作项目签到

合作项目可接入 GM Protocol，为用户提供附加签到任务。合作任务以**教育为目的**，筛选真正理解项目的忠实用户，明确排除一切社交传播任务。

#### 3.4.1 任务类型（7类，合作方框架内自选）

**A类：链上行为验证（强验证，100% 链上）**

| 编号 | 类型 | 说明 |
|------|------|------|
| A-1 | 合约交互验证 | 当日与合作项目任意合约有交互记录 |
| A-2 | 特定功能调用 | 当日调用合作项目指定函数（如 swap、deposit） |
| A-3 | 代币/NFT 持有验证 | 签到时持有合作项目代币/NFT 达最低数量 |
| A-4 | 历史交互验证 | 过去 N 天内有过与合作合约的交互 |

**B类：教育内容验证（前端验证，教育目的）**

| 编号 | 类型 | 内容规格 |
|------|------|---------|
| B-1 | 项目介绍视频观看 | 单集最长 3 分钟，有进度检测（不可快进），长内容须拆分为多集 |
| B-2 | 教程视频观看 | 同上规格 |
| B-3 | 文档/文章阅读 | 单篇为主，滚动到底部 + 最低停留时间（按字数估算） |
| B-4 | 知识问答测验 | 题库最低 30 题（可持续添加），单次随机抽取 1 题，答对解锁 |

**C类：组合验证（强化教育效果）**

| 编号 | 类型 | 说明 |
|------|------|------|
| C-1 | 阅读 + 问答 | 先完成文档阅读，再通过 1 题问答验证理解 |
| C-2 | 视频 + 问答 | 先完成视频观看，再通过 1 题问答验证理解 |
| C-3 | 教育 + 链上 | 先完成 B 类任务，解锁后再完成 A 类链上操作 |

**明确禁止的任务类型：** 关注社交媒体、转发分享、邀请好友、加入群组，以及任何形式的社交传播任务。

#### 3.4.2 独立奖励池机制

每个合作项目拥有独立的 USDC 奖励池，与主 GM 池并行，互不干扰。

**Claim 分配（智能合约锁定，每次 Claim 实时按比例执行，公式见附录 C.3）：**

用户 Claim 单人奖励 R USDC 时，同步触发：
- `R` USDC 从 AMM 回购 gArc 销毁，Claim 池释放等量 gArc 给用户
- `(1/8) × R` USDC 来自储备金库，额外回购 gArc 销毁
- 合作奖励池实际扣除：`(9/8) × R` USDC

**示例**（R=1 USDC，Pg=0.00002 USDC/枚）：
```
奖励池扣除  = 1.125 × 1 = 1.125 USDC
主回购销毁  = 1 / 0.00002 = 50,000 枚 gArc
额外回购销毁= 0.125 / 0.00002 = 6,250 枚 gArc
用户获得    = 50,000 枚 gArc（来自 Claim 池）
单人总销毁  = 56,250 枚 gArc
```

**合作方独立奖励池里程碑体系（与主 GM 池同构）：**

合作方可自定义里程碑参数：

| 参数 | 可选范围 | 说明 |
|------|---------|------|
| 里程碑档数 | 1-4 档 | 与主池同为最多 4 档结构 |
| 每档里程时长 | 最短 1 周，最长 52 周 | 合作方自定义 |
| 每档里程奖励 R_m | 合作方自定义 | 合作方预算决定 |
| 主 GM 池 SBT 门槛 | 无门槛（默认）/ 铜牌以上 / 黄金以上 | 默认无门槛 |

合作项目里程碑达成时，铸造对应合作项目的 SBT 凭证，记录参与历史。

**合作方最低建议锁仓（公式见附录 C.10）：**

系统根据当前日活预估参与人数 `N_est`，自动计算建议锁仓金额供参考，实际锁仓由合作方自主决定。

**示例**（4档里程碑，各档单人奖励 0.5/1/2/4 USDC，N_est=100人）：
```
Lock_min = (0.5 + 1 + 2 + 4) × 100 × 1.125 = 843.75 USDC
```

#### 3.4.3 接入流程

**第一步：申请**
合作方提交：项目基本信息、合约地址、任务类型、内容素材（视频/文档/题库）、合作周期、里程碑参数（档数/时长/奖励金额）、用户门槛（SBT 要求）。

**第二步：审核**
审核内容：项目合法性、题库质量（无引导性答案）、奖励参数合理性、无社交传播任务。审核周期 3-5 个工作日（早期创始人审核，后期移交 DAO）。

**第三步：资金锁定**
系统根据合作参数和当前日活自动计算建议锁定 USDC，合作方转入 GMPartner 合约，链上锁定透明可查。资金锁定确认后任务正式生效。

**第四步：运营期**
任务前端展示，用户完成验证后可签到，奖励自动累积。合作方实时查看数据（完成人数、分发量、剩余奖励池）。

**第五步：到期 / 续期 / 追加**
- **自然到期**：剩余资金按 60% 回购 gArc 销毁 / 40% 注入主 GM 池处理，无退还
- **续期**：重新提交续期周期的任务内容、里程碑参数，系统重新计算建议锁仓金额
- **追加奖励**：仅需注入资金，提交申请后团队审核完成资金锁定即生效，合作周期和任务内容不变

#### 3.4.4 复议与惩戒机制

**触发条件（任意一项）：**
欺诈行为、违规违法内容、恶意操控奖励池、对用户造成明确侵权或损害、DAO 认定的其他严重违规。

**流程：**
```
举报提交
    ↓
立即触发紧急冻结（DAO 多签 3/5，无需投票，即刻执行）
冻结期间：用户已累积未 Claim 的奖励不受影响，仍可正常 Claim
    ↓
证据公示期（48小时，链上可见）
    ↓
DAO 仲裁投票（72小时）
    ↓
    ├── 不成立 → 解除冻结，恢复运营，链上存档
    └── 成立 → 按等级执行惩戒
```

**惩戒等级：**

| 等级 | 情形 | 罚没比例 |
|------|------|---------|
| 轻度 | 内容违规，非主观 | 0%，限期整改后恢复 |
| 中度 | 主观误导，无资金损失 | 20% |
| 重度 | 欺诈、违法 | 60% |
| 极重 | 直接侵害用户资金 | 100% + 永久黑名单 + 链上公告 |

**罚没资金去向（已拍板）：**
- **60%** 执行市场回购 gArc 销毁（最大化通缩）
- **40%** 注入主 GM 奖励池（回馈受影响社区）

**治理激励（正向激励参与）：**

| 角色 | 奖励条件 | 奖励来源与比例 |
|------|---------|-------------|
| 举报方 | 举报成立 | 罚没金额的 10%（从 60% 销毁中划出） |
| DAO 仲裁投票者 | 投票结果与最终裁决一致 | 罚没金额的 5%（从 40% 主池中划出） |
| 举报不成立 | 无奖励 | — |

冻结期间用户已累积未 Claim 的奖励不受影响，仍可正常 Claim。

#### 3.4.5 GM 共享 CD 机制（核心规则）

- 完成任意合作项目的 GM 签到 = 当日主 GM 签到完成
- 连续签到天数共享，主 GM 里程碑积累正常推进
- 当日完成合作签到后，主 GM 签到按钮呈**已完成（不可点击）**状态，显示"今日已通过合作签到完成 GM"
- 无论当日完成多少个合作项目签到，主 GM 连续天数仅累计 1 天
- 合作项目的附加奖励来自各自独立奖励池，与主 GM 里程碑奖励独立计算

### 3.5 身份验证分层体系

防女巫机制随里程碑难度递增：

| 层级 | 触发时机 | 验证要求 | 真实用户成本 | 女巫攻击成本 |
|------|---------|---------|------------|------------|
| 第零层 | 首次签到 | Human Passport Models API 后台扫描 | 零 | 接近零（欢迎参与贡献资金池） |
| 第一层 | 铜牌 Claim | Gitcoin Passport Stamps ≥ 20 分 | 零（已有社交账号直连） | 低~中（需养多平台账号） |
| 第二层 | 黄金/铂金 Claim | Stamps ≥ 20 + ZKPassport 护照验证（或 Stamps ≥ 35） | 极低（5分钟操作） | 高（需真实护照） |
| 第三层 | 传奇 Claim | 第二层 + 双交易所 KYC（Coinbase Verified + 任意一家） | 低（已有交易所账户） | 极高（双重真实 KYC） |

验证一次，同级别重复 Claim 无需再验。

## 4. 经济学模型

### 4.1 GM 资金池分配

每次签到 `f = 0.1 USDC` 的去向（公式见附录 C.1）：

| 用途 | 比例 | 说明 |
|------|------|------|
| 里程碑奖励池 | 80% | 用于里程碑 Claim 奖励 |
| 储备金库 | 10% | 伴随每次 Claim 按 (9/8) 倍额外回购 gArc 销毁（动力源） |
| 协议金库 | 5% | 创始人/团队分配渠道，锁仓后 Claim |
| 合作项目预留 | 5% | 合作方接入奖励渠道，Claim 时同步触发回购销毁 |

**核心验证：奖励池（80%）+ 储备金库（10%）= 90% = (9/8) × 80%，完全自洽。**

### 4.2 回购销毁机制（核心）

**触发条件：** 每次里程碑 Claim 发生时，同步触发储备金库回购销毁。

**执行逻辑（完整公式见附录 C.3）：**

```
设单人应得奖励为 R（USDC），则：
① 奖励池扣除 = (9/8) × R
② 主回购      = R USDC → AMM 买入 gArc → 销毁
③ 额外回购    = (1/8) × R USDC → 来自储备金库 → AMM 买入 gArc → 销毁
④ 用户获得    = R / Pg 枚 gArc（来自 Claim 池，1:1 等量释放）
⑤ 单人总销毁  = (9/8) × R / Pg 枚 gArc
```

**示例**（P=3,246 USDC，黄金 r=10%，N=54人，Pg=0.00002 USDC/枚）：
```
R           = 3,246 × 0.10 / 54 = 6.01 USDC
奖励池扣除  = 1.125 × 6.01 = 6.76 USDC
主回购销毁  = 6.01 / 0.00002 = 300,500 枚 gArc
额外回购销毁= (6.01/8) / 0.00002 = 37,563 枚 gArc
用户获得    = 300,500 枚 gArc（来自 Claim 池）
单人总销毁  = 338,063 枚 gArc
本批（54人）总销毁 = 54 × 338,063 = 18,255,402 枚 gArc
```

**极端场景验证**（GM 池总额 10,000 USDC，当日全部 Claim）：
```
奖励池 R_total = 10,000 × 80% = 8,000 USDC
奖励池扣除    = (9/8) × 8,000 = 9,000 USDC
  其中 8,000 USDC 主回购销毁（来自奖励池）
       1,000 USDC 额外回购销毁（来自储备金库 10%）
GM 池剩余     = 10,000 - 9,000 = 1,000 USDC
             = 协议金库 5%（500 USDC）+ 合作预留 5%（500 USDC）
```

**MEV 防御三层架构：**
1. 用户触发式回购（0.1% 触发激励，随机金额 10%-30%，30 分钟冷却期，先到先得）
2. Chainlink Automation 自动触发（备用层，需确认 Arc 上可用）
3. 项目方 Bot 保底触发（最后保障，行为完全透明链上可查）

**滑点保护：** 每次回购设置最大 0.5% 滑点，超出则失败自动延迟至下次触发。

### 4.3 可持续性验证（基准场景）

基于 Arc Network 真实数据（DAU 约 44,944，真实用户率 10% = 4,500 人，签到渗透率 10% = 450 人起始）：

**C1/C2/C3 用户模型：**
- C1 坚持型（10%，45人）：从不断签
- C2 目标驱动型（25%，112人）：偶尔断签重启，签到约 60% 天数
- C3 随机流失型（65%，293人）：按行业数据断签率流失

**5年奖励池预测：**

| 年份 | 奖励池余额 | 储备金库余额 | 累计销毁USDC |
|------|----------|-----------|------------|
| 第1年 | 2,284 USDC | 286 USDC | 251 USDC |
| 第3年 | 3,056 USDC | 382 USDC | 974 USDC |
| 第5年 | 3,246 USDC | 406 USDC | 1,769 USDC |

奖励池在第3年后趋于稳态（约 3,200 USDC），永不归零。

### 4.4 里程碑收益分析

**单人奖励公式（附录 C.2）：** `R = P × r / N`

**冷启动（零初始注入）稳态收益率（P=3,246 USDC，f=0.1 USDC）：**

> ⚠️ 以下数据为**冷启动无外部资金注入**的自然稳态，仅反映纯USDC层面收益。真实收益 = USDC 奖励 + gArc 持有增值。

| 里程碑 | r | N | R | 签到成本 D×f | 纯USDC收益率 |
|--------|---|---|---|------------|-----------|
| 铜牌 30天 | 1.5% | 79人 | 0.09 USDC | 3 USDC | -97% |

**热启动正向收益门槛（公式见附录 C.4）：**

`P_min = D × f × N / r`

| 里程碑 | P_min |
|--------|-------|
| 铜牌 | 15,800 USDC |
| 黄金 | 4,860 USDC |
| 铂金 | 5,760 USDC |
| 传奇 | 9,328 USDC |

> 热启动注入奖励池 ≥ 16,000 USDC，四个里程碑首轮均可实现正向 USDC 收益。

## 5. gArc 代币经济学

### 5.1 基本参数

| 参数 | 数值 |
|------|------|
| 代币名称 | gArc |

### 5.2 代币分配

**总量方程（完整推导见附录 C.7）：**

```
铸造总量：100亿
立即销毁：-2.1亿（链上不可逆，部署第一天执行）
─────────────────
有效流通：97.9亿 = 47.9亿（Claim池，桥梁）
                + 50亿（初始流动性）

终态推演：Claim池耗尽后，LP 剩余 = 50亿 - 47.9亿 = 2.1亿（永久流通底线）
其中：L = 2.1亿 + 47.9亿 × (10/9) = 50亿（方程自然解）
```

| 用途 | 铸造比例 | 数量（亿） | 说明 |
|------|------|---------|------|
| 初始流动性 | 50% | 50 | TGE 一次性注入 AMM，测试网暂保留权限 |
| Claim 池（桥梁） | 47.9% | 47.9 | 所有渠道 gArc 的来源，纯桥梁，非额外发行 |
| 初期立即销毁 | 2.1% | 2.1 | 部署第一天链上销毁，保证经济学自洽 |

> **注：** 2.1 亿并非永久持有，而是在部署完成后立即销毁。销毁后，97.9 亿有效流通 = Claim 池耗尽后 LP 自然剩余 2.1 亿枚，形成永久流通底线。

### 5.3 通缩机制闭环

```
用户签到 → USDC 进入 GM 池（80%奖励池 / 10%储备 / 5%协议 / 5%合作）
    ↓
各渠道 Claim → 用对应 USDC 从 AMM 回购 gArc → 销毁
    ↓
Claim 池释放等量 gArc → 给用户/团队/合作方
    ↓
储备金库同步 → 按9:1额外回购销毁
    ↓
流动性池 gArc 持续减少 → 最终趋向 2.1 亿永久流通
```

### 5.4 通缩曲线

采用**反向二次曲线**，前端重载，后期放缓，与 BTC 减半的经济叙事结构一致：

**累计销毁比例公式：**

```
C(t) = 1 - (1 - t/6)²     （t为年份，t∈[0,6]）
```

**年销毁率公式：**

```
D(t) = C(t) - C(t-1) = (2×(6-t)+1) / 36 = (13-2t) / 36
```

| 年份t | 年销毁率D(t) | 年销毁量（亿枚） | 累计销毁量（亿枚） |
|------|-----------|-------------|--------------|
| 1 | 30.56% | 14.64 | 14.64 |
| 2 | 25.00% | 11.97 | 26.61 |
| 3 | 19.44% | 9.31 | 35.92 |
| 4 | 13.89% | 6.65 | 42.57 |
| 5 | 8.33% | 3.99 | 46.56 |
| 6 | 2.78% | 1.33 | 47.89 |

2032年（第6年末）预计流通量：50亿 - 47.89亿 ≈ **2.11亿枚**，与 BTC 95.24% 供应量释放的等比状态吻合。

### 5.5 初始资金分配公式

设融资总额为 F，目标第一年销毁率 30.56%：

**GM 池注入量 G 与流动性注入量 P 的关系：**

```
销毁速率 = G × (流通量/流动性注入P) × 10%

由第一年目标销毁率推导：
G / (F - G) = 47.9 × 30.56% / (50 × 10%) = 2.926

解方程：
G = F × 74.5%
P = F × 25.5%
```

GM 池的 G 部分按季度分批注入，共 24 个季度（6年）：

**季度注入量公式：**

```

```

## 6.5 DAO 治理规则

### 6.5.1 治理范围

**必须 DAO 投票的事项：**

| 事项 | 提案类型 | 投票周期 | 时间锁 |
|------|---------|---------|------|
| 季度 GM 池注入（执行/延迟） | 普通 | 48h | 无（时效性） |
| 签到费调整 | 普通 | 72h | 24h |
| 合作项目申请审核 | 普通 | 72h | 24h |
| 合作项目复议仲裁 | 紧急 | 48h | 无 |
| 奖励池分配比例修改 | 重大 | 7天 | 72h |
| 新增身份验证方式 | 普通 | 72h | 24h |
| 合约核心参数修改 | 重大 | 7天 | 7天 |
| 地址关联行为降权确认 | 普通 | 48h | 24h |

**无需投票，任何人可触发：**
- 回购销毁执行（三层触发机制）
- 里程碑奖励 Claim
- 合作任务验证

**创始人多签保留权（早期，逐步移交 DAO）：**
- 紧急暂停合约（3/5 多签，极端情况）
- 合作项目紧急冻结（冻结后 72 小时内必须发起 DAO 仲裁）

### 6.5.2 投票权重模型

**投票权公式：**

```
投票权 = gArc持有量 × 连续签到系数(S) × SBT资格门槛(通过/不通过)
```

**连续签到系数 S（替代锁仓机制）：**

| 当前连续签到天数 | 系数S |
|--------------|------|
| 0天（未签到） | 0.1x |
| 1-29天 | 0.5x |
| 30-89天（铜牌级） | 1x |
| 90-179天（黄金级） | 2x |
| 180-364天（铂金级） | 3.5x |
| 365天+（传奇级） | 6x |

断签后系数立即衰减，无法囤积历史投票权。

**SBT 资格门槛（不同提案类型）：**

| 提案类型 | 最低要求 |
|---------|--------|
| 普通提案 | 铜牌 SBT（当前连续签到中） |
| 资金分配相关 | 黄金 SBT（当前连续签到中） |
| 合约核心参数 | 铂金 SBT（当前连续签到中） |
| 紧急提案 | 黄金 SBT（当前连续签到中） |

断签后 SBT 资格冻结，重新积累至对应里程碑后恢复。

### 6.5.3 50% 攻击三层防御

**第一层：SBT + 实时连续签到加权**
- 高级 SBT 需连续签到 90-365 天，断签后投票权立即衰减
- 女巫行为链上关联检测：同窗口签到 + gas 同源地址群，任何人可提交证明，DAO 确认后降权至 0.1x

**第二层：连续签到系数（替代锁仓）**
- 买入即用仅 0.5x；需连续签到 365 天才能达到 6x 满额
- 真实用户自然积累，攻击者时间成本极高

**第三层：时间锁**
- 普通提案：24h；资金类：72h；核心参数：7天
- 时间锁期间社区可触发创始人多签紧急暂停

### 6.5.4 提案机制

- **发起资格：** 持有铜牌及以上 SBT（当前连续签到中）
- **提案质押：** 100 gArc（通过退还，不通过销毁）
- **通过门槛：** 普通 50%+1；重大参数 67%；核心合约 75%
- **最低参与率：** 总投票权 5%（低于此延期重投）

### 6.5.5 治理演进路线

| 阶段 | 时间 | 治理模式 |
|------|------|---------|
| Phase 0-1 | 测试网 | 创始人多签（3/5），决策透明公示 |
| Phase 2 | 生态建设 | 引入社区投票，创始人保留紧急否决权 |
| Phase 3 | 主网上线 | 完全 DAO 治理，否决权通过时间锁逐年放弃 |
| Phase 4 | 长期 | 完全去中心化 |

- 奖励池百分比制，永不归零
- 储备金库余额始终大于支出（经数学验证）
- 签到费本身即是系统收入，不依赖外部补贴
- gArc 价格下跌时回购销毁力度反而增强（USDC 锚定稳定机制）

### C. 完整公式体系

#### C.1 GM 池日增量公式

```
奖励池日增量   = f × U × 80%
储备金库日增量 = f × U × 10%
协议金库日增量 = f × U × 5%
合作预留日增量 = f × U × 5%
```

**示例**（f=0.1 USDC，U=450人）：
```
奖励池日增量   = 0.1 × 450 × 80% = 36 USDC
储备金库日增量 = 0.1 × 450 × 10% = 4.5 USDC
协议金库日增量 = 0.1 × 450 × 5%  = 2.25 USDC
合作预留日增量 = 0.1 × 450 × 5%  = 2.25 USDC
```

```
R = P × r / N
```

**示例**（P=3,246 USDC，黄金 r=10%，N=54人）：
```
R = 3,246 × 0.10 / 54 = 6.01 USDC
```

#### C.3 完整 Claim 销毁公式（核心）

```
设用户单人应得奖励为 R（USDC），则单次 Claim 执行：

① 奖励池扣除总量  = (9/8) × R = 1.125R
② 主回购金额      = R          （从 AMM 买入 gArc 并销毁）
③ 额外回购金额    = (1/8) × R  （来自储备金库，同步回购销毁）
④ 用户获得 gArc   = R / Pg     （来自 Claim 池，等量释放）
⑤ 总销毁 gArc     = (9/8) × R / Pg
```

**示例**（R=6.01 USDC，Pg=0.00002 USDC/枚）：
```
奖励池扣除  = 1.125 × 6.01 = 6.76 USDC
主回购销毁  = 6.01 / 0.00002 = 300,500 枚 gArc
额外回购销毁= (6.01/8) / 0.00002 = 37,563 枚 gArc
用户获得    = 300,500 枚 gArc（来自 Claim 池）
单人总销毁  = 338,063 枚 gArc
```

**极端场景验证**（GM 池 10,000 USDC，当日全部 Claim）：
```
奖励池 = 10,000 × 80% = 8,000 USDC = R（总）
奖励池扣除 = (9/8) × 8,000 = 9,000 USDC
  其中 8,000 USDC 回购 gArc 销毁
       1,000 USDC 来自储备金库额外回购销毁
GM 池剩余 = 10,000 - 9,000 = 1,000 USDC
  = 协议金库 5%（500 USDC）+ 合作预留 5%（500 USDC）
```

**结论：奖励池（80%）+ 储备金库（10%）= 90% = (9/8) × 80%，完全自洽。**

#### C.4 正向收益门槛公式（热启动）

正向收益条件：`R > D × f`，即 `P × r / N > D × f`

所需最低奖励池：

```
P_min = D × f × N / r
```

**示例**（黄金：D=90天，f=0.1 USDC，N=54人，r=10%）：
```
P_min = 90 × 0.1 × 54 / 0.10 = 4,860 USDC
```

#### C.6 通缩累计曲线（反向二次函数）

```
C(t) = 1 - (1 - t/6)²     t ∈ [0, 6]
```

**年销毁率：**

```
d(t) = C(t) - C(t-1) = (13 - 2t) / 36     t = 1, 2, ..., 6
```

**示例**（t=1，第一年）：
```
C(1) = 1 - (1 - 1/6)² = 1 - (5/6)² = 1 - 25/36 = 11/36 ≈ 30.56%
d(1) = (13 - 2×1) / 36 = 11/36 ≈ 30.56%
年销毁量 = 47.9亿 × 30.56% ≈ 14.64亿枚
```

#### C.7 初始资金分配公式

```
G + L = F
G / L = 第一年目标销毁率 × 总Claim池 / (初始流通量 × 储备金库比例)
      = 30.56% × 47.9亿 / (50亿 × 10%)
      ≈ 2.926

解方程：
G = F × 2.926 / (1 + 2.926) = F × 74.5%
L = F × 25.5%
```

**示例**（F=10,000 USDC）：
```

```

#### C.10 合作项目奖励池最低建议锁仓公式

```
Lock_min = Σ(m=1 to M) [R_m × N_est × (9/8)]

其中：
  M     = 合作方设定的里程碑档数（1-4档）
  R_m   = 第m档里程碑单人奖励（USDC）

```

```
Lock_min = (0.5 + 1 + 2 + 4) × 100 × 1.125 = 7.5 × 100 × 1.125 = 843.75 USDC
```
